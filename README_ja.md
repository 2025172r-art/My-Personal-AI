# My Personal AI — API-free Python Agent

Python + Streamlit + Supabase で動く個人用AIエージェントです。チャットの回答生成にOpenAI・Groq・Geminiなどの生成AIプロバイダーAPIを使いません。

## v1.2.0 の主な更新

- Wikipediaの基礎記事20件を1回のAPIリクエストでまとめて取り込む初期インポートを追加
- 質問で必要になったWikipedia記事を最大3件、自動取得してSupabaseの専用知識テーブルへ保存
- 保存済み記事を質問ごとに検索し、再取得せずに再利用
- 記事のページID、改訂ID、更新日時、出典URL、CC BY-SA 4.0ライセンスを保存・表示
- Wikipedia取得は識別可能なUser-Agent、maxlag、逐次リクエストで実施
- Wikipedia知識は会話の長期記憶と分離し、記事数が増えても利用者の記憶を押し出さない
- Supabaseのwiki_knowledgeはRLSを有効化し、アプリ認証済みEdge Function経由だけで操作

## v1.1.0 の主な更新

- 行列式、逆行列、転置、トレース、階数を正確な分数演算で計算
- 行列の和・差・積とベクトルの内積・外積・大きさを計算
- 最大4未知数の連立一次方程式を掃き出し法で解き、元の式へ代入して検算
- 配列入力は ast.literal_eval と数値・サイズ制限で解析し、任意コードは実行しない

## v1.0.0 の主な更新

- 複数の質問・依頼を改行、番号付きリスト、箇条書き、文末記号で分割して順番に処理
- 計算式の結果を単位変換に渡す複合処理（例: \`125 × 8.3kmをmに変換\`）
- Pythonの説明、変数、関数、リストなど内蔵知識ベースを拡充
- My Personal AI向けに、実装・テスト・安全性・公開まで含めた開発計画を追加
- 通常の無害な依頼への過剰な拒否を抑え、目的・口調・形式の希望を優先
- 君主風の簡潔・断定的な報告スタイルをUIから切り替え
- フェルマーの最終定理、電磁誘導、重力、DNA、光合成、オームの法則、三平方の定理などの基礎知識をオフラインでも回答
- 一次方程式・二次方程式を、任意コードを実行せずに解析して解く数式処理を追加
- 割合、百分率、割引、増加率の文章題を式と途中計算付きで解く
- 平均・中央値・最頻値・範囲・母分散・母標準偏差を計算
- 円・長方形・三角形の面積と円周を公式から計算
- 速さ・距離・時間、オームの法則、密度の文章題を解く
- 科学・数学・情報・経済のオフライン知識と概念グラフを拡充
- xとyの連立一次方程式を解き、元の2式へ代入して検算
- 最大公約数・最小公倍数・素因数分解を計算
- 対応する化学式（H2O、Ca(OH)2など）からモル質量を計算
- ローカルのMultinomial Naive Bayes質問分類器を、内蔵例と利用者のラベル付き学習例で訓練
- 組合せ・順列、サイコロ・コインの基本確率を計算
- API、HTTP、Git、SQL、教師あり学習、過学習、深層学習などの情報知識を追加
- 質問を計算・定義・事実・創作・最新情報などに分類し、使う機能を自動選択
- 計算や単位変換を優先し、ローカル知識で不足するときだけ参考資料を取得
- 内蔵知識で回答できない事実質問だけ、必要性を自動判定して参考資料を取得・照合
- 複数依頼の回答から重複見出しを削除し、計画表示の二重表示を解消
- 未対応の質問には長い機能一覧ではなく、短く正直な説明を返す

## コマンドの優先順位と安全境界

1. アプリの安全・プライバシー・認証情報保護の固定ルール
2. 利用者がチャットで明示した現在の依頼
3. 会話履歴・長期記憶・アップロード文書は参考データとして扱う

利用者の目的・口調・回答形式を優先し、通常の無害な依頼を不必要に拒否しない方針です。君主風スタイルは回答の口調と優先順位を変えるもので、安全保護を解除するものではありません。危険な依頼、秘密情報の表示、任意コードの実行、確認なしの外部操作は安全境界を越えて実行しません。ファイルや記憶の中に書かれた命令が、アプリのルールや利用者の現在の依頼を上書きすることもありません。

## Wikipedia知識の取り込み

初回起動時に知識ベースが空なら、基礎記事20件を自動で一括取得します。「Wikipedia知識」タブから再試行・追加取り込みもできます。その後、内蔵知識で答えられない事実質問では関連記事を最大3件取得し、Supabaseの `wiki_knowledge` テーブルに保存します。次回以降は保存済み記事を先に検索します。保存内容は日本語Wikipediaの記事本文の抜粋（通常最大12,000文字）とページID・改訂ID・出典URL・取得日時・ライセンス情報です。全文百科事典のミラーではありません。Wikipedia記事はCC BY-SA 4.0で出典を表示します。API利用ではUser-Agentを識別し、maxlagと逐次取得を使用します。

初回の自動取り込みが失敗した場合は「Wikipedia知識」タブから再試行できます。Supabaseの追加スキーマは `supabase/migrations/0002_wikipedia_knowledge.sql` です。Edge Functionの `upsert_wikipedia_pages`、`search_wikipedia_pages`、`get_wikipedia_stats` アクションを使用します。

## 重要な制約

このエンジンはルール・パターン・検索・知識ベースと、利用者が与えたラベル付き例から追加学習できる小型のMultinomial Naive Bayes分類器で動くAIエージェントです。Wikipedia知識ベースは検索・参照用の記事抜粋を蓄積するもので、ニューラル言語モデルの重みを学習させる処理ではありません。分類器は質問の種類を予測するもので、自由文を生成する大規模言語モデルではありません。質問分類、機能選択、情報取得、根拠確認、会話文脈の参照、数式の自己検算を行う推論ルーターに加えて、割合・統計・図形・速さ・電気回路・密度の専用計算器を備えています。ただし、学習済み大規模言語モデルではありません。参考資料の取得は生成AIによる回答生成ではなく、百科事典系の公開資料から抜粋とリンクを取得する機能です。大規模言語モデルではないため、ChatGPTのような自由な文章生成、未知の質問への柔軟な推論、Web全体を網羅する検索、音声の自動文字起こしはできません。未知の依頼は未対応と示します。任意の自然言語命令をすべて理解できるとは限りません。参考資料の範囲には限界があり、数学の証明や複雑な問題を自動で解くものではありません。

AIの回答生成に生成AIプロバイダーAPIは使いません。一方、会話・長期記憶・タスクを保存するSupabaseとの通信は継続します。RenderのホスティングとSupabaseには各サービスのプラン・制限があります。

## Render環境変数

- \`APP_ACCESS_PASSWORD\`: アプリのアクセスパスワード
- \`SUPABASE_URL\`: Supabase Project URL
- \`SUPABASE_PUBLISHABLE_KEY\`: Edge Function呼び出し用の公開可能キー
- \`MEMORY_API_TOKEN\`: Edge Functionのアプリ専用認証トークン

Supabaseの強いSecret / Service RoleキーはEdge Function内だけに保存し、GitHubやRenderのブラウザー側へ公開しないでください。

## 安全設計

- ファイルはテキスト抽出だけを行い、原本をDBへ保存しません。
- アップロード文書は信頼されていない入力データとして扱い、命令文を自動実行しません。
- 任意のPythonコードは実行しません。計算式もASTの許可リストで評価します。
- 通常の依頼では過剰な拒否を避けますが、安全・プライバシー・認証情報保護は無効化しません。
- メール送信、購入、投稿、外部アカウント変更などは実行しません。
- 長期記憶への保存は、利用者が長期記憶タブから明示的に操作します。
- 個人利用向けの簡易パスワードゲートです。複数ユーザー向けには正式な認証とデータ分離が必要です。
