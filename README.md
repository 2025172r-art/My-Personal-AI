# My Personal AI

Chromebook, Windows, Mac で使える個人用AIエージェントの初期版です。

日本語の詳細な説明とセットアップ手順は [README_ja.md](README_ja.md) を参照してください。

主な機能:
- OpenAI Responses API によるチャットと Web 検索
- Supabase / SQLite による長期記憶と会話履歴
- PDF / DOCX / TXT / MD / CSV / XLSX の読み込み
- 音声入力・文字起こし・音声読み上げ
- Planner / Worker / Reviewer による複数AIワークフロー
- Streamlit のブラウザUI

APIキーやパスワードなどの秘密情報は、このリポジトリに保存しないでください。
この初期版は個人利用向けです。公開前にアプリのパスワードとサーバー側Secretsを設定してください。
